# RideMesh: An AI-Powered Dynamic Carpooling and Real-Time Mobility Management System

RideMesh is a proposed intelligent carpooling system that aims to make urban commuting more efficient by connecting drivers and passengers travelling along similar routes.

Unlike basic proximity-based matching, RideMesh focuses on route compatibility, travel-time feasibility, vehicle capacity, passenger waiting time, and driver detours to recommend suitable ride-sharing opportunities.

### Key Features (Planned)

- **AI-Assisted Ride Matching:** A multi-factor compatibility score to rank feasible driver–passenger matches.
- **Route-Aware Optimization:** Matching based on route overlap, travel direction, and time constraints.
- **Dynamic Pickup Recommendations:** Suggesting practical meeting points to improve ride efficiency.
- **Real-Time Ride Monitoring:** Planned GPS tracking, estimated time of arrival (ETA) updates, and route-deviation monitoring.
- **User-Controlled Decisions:** Riders can review, accept, reject, or modify recommendations before a ride is confirmed.
- **Cost and Sustainability Analysis:** Planned shared-trip cost estimation and CO₂ impact estimation.
- **Performance Evaluation:** A proposed comparison against nearest-driver, fixed-pickup, and rule-based matching baselines.

### Project Status

Currently at the interim research and planning stage, covering problem identification, literature review, research-gap analysis, proposed workflow, match-scoring design, and evaluation planning. Implementation and experimental validation are planned for subsequent development stages.

### Objective

To explore how intelligent, route-aware ride matching and flexible pickup recommendations can reduce waiting time, unnecessary detours, and travel costs while keeping users in control of ride decisions.
